# Run the survey natively on the VPS with embedded SQLite

The user chose an existing 2 GB GoDaddy Ubuntu VPS and its Nginx and PM2 installations instead of Cloudflare Workers/D1. We retain Astro, but use one native Node process (the existing VPS Node 22.19 is supported) and SQLite to keep resource use low and preserve the existing SQL model; this trades managed database/hosting operations for explicit migrations, server maintenance and manual recovery. Nginx uses the existing Certbot/Let’s Encrypt workflow and PM2 uses the existing deployment account. SQLite is embedded rather than a separate database server: Docker is optional for maintenance utilities, while the application and durable data stay on the host. The temporary DNS-only hostname is staging, both approved administrator emails have equal permissions, and automated backups are intentionally omitted at the user's request.

The user subsequently chose to remove Cloudflare runtime dependencies. Authentication is now two separate local email/password accounts with equal permissions, scrypt password hashes, expiring hashed sessions, and server-command password resets that revoke sessions. Public submissions use signed form tokens, a honeypot, minimum form age, and SQLite-backed reader/network rate limits. This removes external authentication and challenge setup at the cost of locally managing credentials and having weaker bot detection than Turnstile. DNS-only routing goes directly to Nginx and Certbot HTTPS.
