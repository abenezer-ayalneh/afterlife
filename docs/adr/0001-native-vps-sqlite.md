# Run the survey natively on the VPS with embedded SQLite

The user chose an existing 2 GB GoDaddy Ubuntu VPS and its Nginx and PM2 installations instead of Cloudflare Workers/D1. We retain Astro and Cloudflare Access/Turnstile, but use one native Node process (the existing VPS Node 22.19 is supported) and SQLite to keep resource use low and preserve the existing SQL model; this trades managed database/hosting operations for explicit migrations, server maintenance and manual recovery. Nginx uses the existing Certbot/Let’s Encrypt workflow and PM2 uses the existing deployment account. SQLite is embedded rather than a separate database server: Docker is optional for maintenance utilities, while the application and durable data stay on the host. The temporary Cloudflare hostname is staging, both approved administrator emails have equal permissions, and automated backups are intentionally omitted at the user's request.
